# 地形预瞄与原地转向设计决策（2026-08-19）

## 已锁定边界

- 正式地图的接触参数继续全图固定为 `friction="1 0.5 0.5"`、`condim="3"`，不作空间随机化。
- 滑动摩擦系数大于1并不等同于粘附力，但当前项目没有必要用大于1的值掩盖控制问题。
- 暂不增加关节、可动躯干、额外腿或吸附力；只有现有结构的观测与控制方案仍失败后，才重新评估结构改造。
- 新地形观测默认关闭，旧122维检查点和封存实验保持可重放。

## 可开关的局部地形预瞄

`FixedGoalTerrainWrapper` 可在现有122维局部运动观测后追加13个值：

1. 沿目标前进方向0.5 m、1.0 m和1.5 m处，各取左、中、右三个相对地形高度，共9值；
2. 当前位置地形法向量在“目标前向、目标左向、世界向上”坐标系中的3个分量；
3. 沿目标前进方向的有符号坡度角1值。

该扩展不向底层策略提供全局坐标、目标坐标或地图身份。当前只完成接口、边界与数值烟雾测试；启用后观测维度从122变为135，旧策略不能直接作为135维策略运行。后续训练应扩展策略和价值网络第一层：复制原122列权重，把新增13列初始化为0，并使用新的优化器状态。这样可以在初始时保持旧策略输出，再让训练逐步学习地形信息。

## 当前是否支持原地旋转

当前软件接口不支持严格的原地旋转。`set_external_curve_command` 要求前进速度严格大于0，并按

`curvature = yaw_rate / speed`

检查曲率上限；固定目标控制器的最大角速度同样是

`maximum_yaw_rate = target_speed * maximum_abs_curvature`。

因此，当目标前进速度为0时，当前接口无法给出非零角速度。这是命令和训练分布的限制，不能据此判定四条腿或8个驱动关节在机械上无法转向。

现有Ant结构原则上可以通过左右足端产生相反的切向力和交替换足，实现“近似原地”的偏航旋转。不过，旋转过程中支撑多边形和质心投影会变化，要求躯干中心在每个瞬间绝对不移动既不现实，也没有必要。正式指标应使用有限容差，例如报告完成90度旋转时的躯干中心净位移、累计平面路径、最大偏离半径、完成时间、跌倒、四足腾空和滑动，而不是要求数学意义上的零位移。

下一阶段如需启用原地转向，应先把角速度命令与曲率解耦，允许 `speed = 0` 且 `yaw_rate != 0`，再按“平地小角度—平地90度—坡面小角度—复杂地形转向”的课程单独训练。该能力不能由当前只见过正前进速度的检查点直接推断。
