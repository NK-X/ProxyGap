# Ant-v5 平地曲线步态优化诊断（2026-08-18）

## 结论

当前 V4 checkpoint 能完成变曲率椭圆八字路线，但不能视为“自然前进步态”。其主要缺陷不是外层路线控制器，而是底层策略在前进指令下仍产生显著横向速度，并长期依赖两条腿支撑。

三类有限微调均未解决四腿自然参与：

1. 只惩罚四足同时离地，略微降低腾空比例，但支撑失衡恶化；
2. 惩罚单足长时间不触地，没有稳定改善弱腿参与；
3. 加强横向速度约束，持续改善运动方向，但没有消除约 24--25 度的斜行姿态，也没有恢复四腿均衡接触。

因此，V7、V8、V9 和 V10 均保留为开发诊断 checkpoint，不应报告为最终优化模型。若以“自然四足步态”为硬要求，下一版应从未学习横移切换的较早平地 checkpoint 重新训练；若该 checkpoint 无法恢复，则应明确选择一种目标步态（例如对角小跑），加入可观测的步态相位或接触历史，再进行从头或长程训练。

## 冻结比较条件

- 路线：两个相切椭圆，半长轴 5 m，半短轴 4 m；
- 曲率范围：0.1600--0.3125 m^-1；
- 目标速度：0.8 m/s；
- 控制器：pure pursuit，lookahead 0.4 m，yaw feedback gain 0.5 s^-1；
- 评估种子：53316；
- 策略输入：局部前进速度、零横向速度、偏航角速度及朝向误差；路线坐标不进入策略；
- 接触量在 0.05 s 控制步末采样，适用于同一仿真设置内的相对比较，不等同于高频力板测量。

## 下一项必要决策

在实施正式“自然步态”训练前，需要冻结自然步态的操作性定义。当前最可复现的候选是：指定对角小跑，要求两组对角腿交替支撑、每足在固定时间窗内参与、禁止四足同时离地，并把步态相位或接触历史加入 observation，避免使用对策略不可见的历史奖励状态。
