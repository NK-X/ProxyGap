# Ant-v5 平动支撑优化诊断：V11--V22（2026-08-18）

## 结论

本轮没有得到可宣称“禁止四足同时腾空”的合格策略，因此没有进入斜面、凸曲面、凹曲面或混合地形验收。

奖励权重微调可以在支撑、前进速度和转弯能力之间移动，但不能同时满足三项。V22 将四个足端的当前接触状态显式加入 observation 后，能够同时保留前进和接近 V4 的转弯能力，但 600 步平地评估中的平均腾空比例仍为 26.9%。这说明当前接触掩码是有效且可对接的结构性接口，但仅有瞬时接触状态还不足以学出无腾空支撑策略。

自然步态外观仍不在本轮目标内。本轮只处理严重动作不协调：四足同时离地、明显横向漂移、持续倾斜、前进能力丢失及转弯能力遗忘。

## 固定比较条件

- 机器人 XML、质量、执行器、动作范围和控制间隔保持不变；
- 平地摩擦保持 MuJoCo 编译值 `[1.0, 0.5, 0.5]`，`condim=3`；
- 目标指令为 0.8 m/s 前进，不提供横移或后退指令；
- 平地开发筛查为 10 个共同 evaluation seed（61001--61010），每个 600 控制步，即 30 s；
- 曲线回归使用共同 evaluation seed base 55001，包含直线、左右缓弯、左右中弯和 S 曲线；
- 所有比较均使用确定性策略动作；
- 每个版本只有一个训练 run。本结果属于开发诊断，不能作为统计显著性或泛化优势证据。

## 奖励微调结果

V11--V21 依次测试了：

1. 强二值腾空惩罚；
2. 中等二值腾空惩罚；
3. 更强的身体竖直速度约束；
4. 腾空惩罚与更强水平速度跟踪的联合约束；
5. 交替进行支撑加压与进度恢复；
6. 在保留支撑约束时重新引入曲率；
7. 在变曲率分布中恢复水平进度。

强腾空惩罚单独使用时，策略主要通过降低运动强度来减少腾空。提高水平速度跟踪可以恢复进度，但腾空会反弹。该可重复权衡说明固定奖励权重已接近当前 observation 和策略结构下的实用边界。

## V22 结构性实现

- observation 从 118 维扩展为 122 维；
- 末四维依次为四个足端的当前真实接触指示；
- 接触状态来自 MuJoCo 足端--world 接触，而非足高阈值；
- 原策略和价值网络的既有列逐项复制；
- 新增四列在两个首层网络中均初始化为零；
- 转移时动作最大绝对误差满足 `1e-7` 容差；
- observation 不包含路线坐标、地形编号或指定步态相位。

V22 首次运行发现新 PPO 对象的 timestep 计数从零开始，原配置会把计划的 262k 误解释为约 2.2M。该超预算运行已中止，未完整 checkpoint 的临时输出已删除；训练脚本随后恢复来源模型累计 timestep，再按 131k 和 262k 两个有界阶段重跑。最终 execution record 与 checkpoint 均来自修正后的运行。

## 下一轮结构性方向

下一轮不再继续扫固定奖励权重。应在 V22 接口上追加支撑历史，例如每足“距上次接触的时间”或短窗口接触历史，使策略能判断接触正在建立还是正在丢失。随后使用带约束的训练门槛：

1. 前向位移至少保留 V4 的 90%；
2. 训练过程中混采直线与旧曲率分布，避免遗忘转弯；
3. 平地四足腾空比例和最长连续腾空必须同时下降；
4. 若仍不能接近零，再引入明确的至少一足支撑调度或安全层，而不是继续增加标量惩罚；
5. 只有平地门槛通过后，才进入固定摩擦的斜面、凸曲面、凹曲面和混合地形测试。

该支撑历史不等同于提前优化自然步态外观；它只处理当前被定义为违规的全足离地行为。
