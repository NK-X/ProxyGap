# Final PAIR0 标准坡度能力边界正式报告

## 1. 结论

最终 V3 `PAIR0_ADAPT` checkpoint 在本次冻结测试网格中的结果为：

- 上坡 4°、8°、12°测试点通过全部门槛；16°首次失败，20°再次失败。因此，12°只能表述为本协议下的**连续被测下界**，16°只能表述为首个**被测失败上界**，不能据此声称机器人的物理最大爬坡角为 12°或介于 12°与16°之间。
- 下坡 8°和16°测试点通过，4°、12°和20°失败，结果明显非单调。由于最低正角度4°已经失败，下坡不存在可报告的连续正角度被测下界；16°只能表述为“16°这一离散测试点通过”，不得表述为机器人能够连续稳定通过0–16°下坡，更不得称为最大下坡能力。
- 55轮中均未发生摔倒、躯干触地、持续非足端接触或修正后持续滑动；每轮的力限定支撑分母均大于零。主要限制是有效推进，而不是正式滑动指标。唯一额外安全失败是上坡20°的全区间零足端比例超门。
- 能耗保持为仅测量项，没有进入奖励或判定门槛。本实验只能确认四个既定能耗代理均为有限值，不能据此宣称节能、电池能耗降低或电气效率改善。

该工件已完成正式运行后独立只读审计，结论为 `GO`，未发现 P0/P1 阻断。

## 3. 预声明门槛

每个坡度由同一固定策略在5个新评估种子上运行。一个坡度测试点只有在全部检查均通过时才判为通过：

1. 摔倒数、躯干触地轮数和持续非足端接触轮数均为0；
2. 每个种子的力限定支撑分母均大于0；
3. 修正后持续滑动物理子步数和滑动事件数均为0；
4. pooled full-interval zero-foot fraction 不高于 `0.0580555556`；
5. 上坡平均最佳推进不少于 `6.1857992362 m`，下坡平均最佳推进不少于 `8.8113570803 m`。

平地仅作为安全参考，不增设事后推进门槛。所有门槛沿用既有绝对值，没有根据本次结果调整。

## 5. 边界解释与阈值敏感性

### 5.1 上坡

上坡表现随角度整体恶化，并在16°首次跨过推进门槛。12°的平均最佳推进为 `7.334866 m`，高于门槛；16°下降到 `5.531944 m`。20°进一步下降到 `2.238192 m`，同时零足端比例达到 `6.8333%`，超过 `5.8056%`门槛。

这些结果支持“在所测协议中，16°以上推进能力明显退化”的描述，但不识别物理极限。未测试13°、14°、15°，也未重复训练独立策略，因此不能插值出精确最大角度。

### 5.2 下坡

下坡4°平均推进为 `8.770105 m`，仅比固定门槛低 `0.041252 m`，约低0.47%；而8°和16°通过，12°和20°失败。该非单调模式同时伴随较大的种子间推进差异，例如下坡4°各轮约为 `6.5589–10.6773 m`。

因此，下坡4°的失败对门槛及小样本均较敏感，但正式判定仍必须保持为FAIL，不能事后放宽门槛。现有证据更适合解释为“单一固定策略的下坡推进具有显著条件/种子敏感性”，而不是一个随坡度单调变化的机械能力边界。需要独立训练种子或更密集的预声明角度网格，才能支持更强的下坡能力结论。
