# 固定标准场景支撑小范围课程：诊断与单因素试验

日期：2026-08-19<br>
状态：开发阶段、预声明门槛判定完成；干预未保留

## 1. 本轮问题与边界

本轮只回答两个问题：此前约 68% 的“四足端无接触”有多少是控制步末端采样造成的高估，以及在不改结构、不改能耗、不改地形摩擦的条件下，现有“每足接触间隙”项是否值得继续训练。

固定条件如下：原 Ant XML、8 自由度、135 维观察、仅前进指令、相同高层控制器、摩擦 `[1.0, 0.5, 0.5]`、`condim=3`、`ctrl_cost_weight=0.5`，以及 V2 相对任务能耗继续只测量、不进入本轮优化。没有增加关节、吸附力或新的能耗公式。

为减少归因混淆，建立四个 257×257、20 m×20 m 的标准场景：数值平地、固定 8° 上坡、固定 8° 下坡和凹坑出口。三维机器人、质量、执行器、动作范围和控制周期均保持不变。

## 2. 高频接触审计

原指标只读取每个 0.05 s 控制步最后一个 MuJoCo 子步。本轮在动作保持不变的情况下，对每个控制步的 5 个 0.01 s 物理子步逐一读取接触。

135 维源策略、seed 75802 的结果如下：

| 场景 | 控制步末端四足端无接触 | 整个 5 子步周期均无足端接触 | 末端零接触中、此前子步曾接触 |
|---|---:|---:|---:|
| 平地 | 74.75% | 33.00% | 55.85% |
| 8° 上坡 | 68.25% | 25.50% | 62.64% |

因此，末端采样明显高估了完整控制周期的悬空；但 25.5%–33.0% 的控制周期在五个子步中始终没有任何指定足端接触，不能把问题全部解释为采样误差。上述末端零足端接触期间，没有检测到躯干或其他机器人几何体接地；末端足端掩码与第五个子步逐值一致，说明审计与旧指标的接口对齐。

这里仍需保留术语边界：“完整周期零足端接触”表示四个指定 distal-foot geom 未与世界几何体接触，不等同于已由连续时间解析证明的弹道跳跃。

## 3. 四场景基线

135 维 stage-1 源 checkpoint 在 3 个种子×4 场景、每轮 600 控制步的诊断中：

- 12 轮无摔倒；平均最佳进度 9.482 m；
- 控制步末端四足端无接触率 69.681%；平均支撑足数 0.350；
- 相对地形法向的躯干倾斜 RMS 0.084 rad；
- 修正后的持续滑动率 0.986%。

作为只读诊断对照，118 维 V20 支撑 checkpoint 的平均最佳进度为 6.469 m、末端无接触率 69.018%、平均支撑足数 0.353，并出现 2/12 摔倒。它没有在当前固定目标/heightfield 合同下复现此前单独平地测试中的低无接触结果；这不等于证明 8 自由度结构已经达到上限。

预声明选择门槛为：平均末端无接触率至少 25%，至少两个场景的平均最长单足接触间隙超过 0.75 s，且任一高频审计场景的完整周期零足端接触率至少 10%。三项均满足，因此允许启动一个单因素干预。

## 4. 训练前兼容修正与失败保留

第一次正式启动在 PPO 继续训练之前失败：源 checkpoint 的九个局部高度观察声明为 `[-6,+6] m`，而初版标准场景按各自高度极差生成 Box 边界。虽然维度同为 135，Stable-Baselines3 仍正确拒绝了不相等的观察空间。该目录保留为 `paired_seed_62804`，没有生成候选模型。

唯一一次重试只增加可选、默认关闭的 `local_terrain_height_bound_m` 元数据参数，并在本标准试验中固定为 6.0。定向测试逐值确认新环境的观察空间等于源 checkpoint；实际观察值、奖励、地形、XML、摩擦和能耗计算均未改变。重试使用新目录 `paired_bound6_seed_62804`。

## 5. 单因素 W0/W1 配对试验

两组都从同一个 `checkpoint_2596864.zip` 出发、seed 62804、4 个并行场景，各追加 65,536 步：

- W0：`foot_contact_gap_shaping_weight=0`；
- W1：仅把该权重改为 1；0.5 s grace 和 0.5 s scale 不变。

评估使用相同 seeds 76801–76803、四场景、每轮 600 步。预声明保留条件为：末端无接触率绝对下降至少 5 个百分点、平均支撑足数增加至少 0.1、最佳进度比例至少 0.8、不增加摔倒、持续滑动率增量不超过 2 个百分点。

| 指标 | W0 对照 | W1 干预 | W1−W0 / 比例 |
|---|---:|---:|---:|
| 末端四足端无接触率 | 69.417% | 69.000% | −0.417 个百分点 |
| 平均支撑足数 | 0.35431 | 0.35458 | +0.00028 |
| 平均最佳进度 | 7.388 m | 7.123 m | 比例 0.964 |
| 摔倒 | 0/12 | 0/12 | +0 |
| 修正持续滑动率 | 0.861% | 1.306% | +0.444 个百分点 |
| 累积动作平方 | 154.40 | 161.54 | +4.63% |
| 绝对力矩时间积分 | 5255.41 N·m·s | 5377.73 N·m·s | +2.33% |
| 正机械功代理 | 3191.34 J | 3370.70 J | +5.62% |
| 绝对机械功代理 | 3751.92 J | 3944.20 J | +5.12% |

正式保留门槛未通过。无接触率改善仅为所需幅度的约 8.3%，支撑足数几乎不变，进度下降且所有四项控制/机械工作代理均上升。W0 与 W1 均为 0/12 到达；相同标准场景诊断中的 source 为 2/12 到达，平均最佳进度 9.482 m，而 W0 为 7.388 m。因此 W1 checkpoint 只保留为负结果，W0 也不晋级；原始 135D source checkpoint 继续作为 incumbent。

单 seed 的训练后高频审计提供一个仅供机制解释的线索：完整周期零足端接触在平地由 32.0% 变为 30.0%，在上坡由 19.25% 变为 16.0%，但相同轮次的控制步末端零接触反而增加。可能发生的是接触时序在 0.05 s 窗口内轻微移动，而不是形成更长、更可靠的支撑期。由于这只是两个场景、一个审计种子，不能把它作为保留依据。

## 6. 结论与下一步

当前最直接的结论不是“摩擦不足”或“关节数量不足”，而是现有接触间隙惩罚在短预算内没有改变宏观支撑占空比。它可能过于稀疏、与策略已有局部最优冲突，或只改变接触相位而没有改变承重支撑。继续单纯增加 W1 训练步数缺乏本轮证据支持。“修正持续滑动率”字段实际只在控制步末端采样，故应解释为 endpoint-sampled sustained slip；它不是物理子步级的连续滑动积分。

按照快速模式的停止规则，本轮不再同时引入足端净空、接触时序、速度课程或结构修改。下一轮若继续，应只选一个新的、可直接作用于“物理子步支撑占空”的干预，并沿用同样的高频审计与配对门槛；在此之前不应增加关节或吸附力。

本结论只属于一个训练 seed 和三个评估 seeds 的开发筛选，不是总体性能或泛化性的统计证明。
