# 固定地图候选路线跟随探索性评估（2026-08-19）

## 1. 结论先行

本轮实验验证了一个有限但重要的结果：将高层目标从“始终指向最终终点”改为“沿 16° 坡度上限候选折线逐点前视”，能够在部分 reset seed 中显著增加空间推进；但尚未得到任何满足安全和终点稳定驻留要求的完整任务。30 轮配对实验中：

- 最终位置驻留成功存在于 `D0` 与 `R_v040_l030_k020` 各 1/5 轮；
- 稳定驻留成功为 0/30；
- 合格完成为 0/30；
- 因而没有任何一轮可以进入“时间 + 相对任务能耗”的有效解集合或 Pareto 排序。

路线规划不是目前唯一或首要瓶颈。表现较好的路线条件仍有约 65%--67% 的四足端同时无接触比例和约 24% 的接触切向速度超限比例；低层支撑与接触控制仍会使高层路径方案失效。这里的结果不能解释为“机器人已学会最优路径”。

## 2. 变更边界

本轮只新增独立评估脚本与配置，没有修改：

- 现有环境 wrapper；
- PPO 训练或 checkpoint；
- 运动策略、奖励函数或终止规则；
- 固定地图及摩擦参数；
- 现有能耗文件或能耗实现。

评估时固定使用同一 checkpoint、同一固定地图、摩擦参数 `[1.0, 0.5, 0.5]` 和 `condim=3`。动态前视点仅在外层环境实例上重写 `goal_xy`；`terminate_on_success=False`，最终到达、驻留和安全性均由独立脚本重新计算。V2 相对任务能耗尚未实现，已有正/负机械功只作为诊断日志记录，不参与奖励、路线代价或排名。

## 3. 候选路线与接口验证

候选路线是本轮按已知 16° 坡度上限独立重建的 Hybrid-A* 风格工程候选，不是经过证明的全局最优路线，也不是旧摘要路线的精确复现：

| 路线量 | 本轮重建值 |
|---|---:|
| 路线长度 | 106.150 m |
| 累计上升 | 5.711 m |
| 累计下降 | 3.481 m |
| 走廊采样最大坡度 | 15.968° |
| 累计转角 | 129.073° |
| 折线 waypoint 数 | 214 |
| 首段方向 | 90° |

已进行以下运行时验证：

1. 外层 `goal_xy` 可在每一步设置为折线前视点；
2. 重建后的 122 维 observation 形状不变，命令相关索引确实随动态目标改变；
3. 指定初始 yaw 时，仅重写 `env.unwrapped.init_qpos[3:7]` 的朝向，其余 seeded qpos/qvel 噪声由原 reset 保留；
4. 目标 78° 的 seed 74803 reset 实际 yaw 为 82.307°，说明原始姿态噪声仍存在；默认场景 45° 的同一 seed reset 实际 yaw 为 51.918°；
5. 每个输出目录冻结脚本、配置、哈希、逐轮记录、逐步 trace 与 API 审计，且不会覆盖旧结果。

## 4. 评估设计

### 4.1 独立因素

- `D0`：原直接终点控制 + 场景默认约 45° 初始朝向；
- `D1`：原直接终点控制 + 约 78° 初始朝向，只改变初始 yaw；
- `R`：候选路线前视控制 + 约 78° 初始朝向；
- `R45`：候选路线前视控制 + 场景默认约 45° 初始朝向，用于解除“路线效果”和“强制 78° 初始朝向”的混杂。

路线网格考察速度 0.4/0.5 m/s、前视距离 3/5 m、最大曲率 0.12/0.20 m^-1。先对 seed 74803 做完整筛查，随后将所有最大曲率 0.20 m^-1 的四种组合与 `D0`、`D1` 在 seeds 74801--74805 上配对评估。全部失败轮均被保留。

### 4.2 合格门控

“进入终点”不等于合格完成。合格完成要求依次通过：

1. 进入最终目标半径 1.5 m；
2. 在半径 2.0 m 内连续保持 2 s（40 个控制步）；
3. 同一驻留窗口内同时满足至少两个足端支撑、平面速度不超过 0.15 m/s、根部角速度不超过 0.5 rad/s、躯干倾角不超过 20°、接触足端切向速度不超过 0.2 m/s；
4. 全 episode 无摔倒、无四足端同时无接触、无接触速度违规。

只有通过上述硬门控的任务，才有资格比较时间或未来的 V2 相对任务能耗。

## 6. “到达但不合格”的逐步审计

`R_v040_l030_k020`、seed 74801 是本轮唯一完成路线条件位置驻留的 episode：

- 最终距离 0.599 m，最小距离 0.299 m；
- 在终点 2 m 圈内最长连续 385 步；
- 首个 40 步位置驻留窗口中，25/40 步四足端同时无接触；
- 支撑足数量最大 2、均值 0.425；
- 13/40 步接触切向速度超限；
- 窗口最大平面速度 0.750 m/s；
- 最长稳定驻留为 0 步；
- 全 episode 四足悬空率 68.30%，接触速度超限率 23.68%。

因此该轮只能称为“空间到达”，不能称为稳定、安全或任务完成，也不能进入时间--能耗目标排序。

## 7. 初始朝向和高层坡度调速消融

### 7.1 初始 yaw 不是无害设置

仅把直接控制的初始朝向由场景默认值改为约 78°，五 seed 平均净推进由 18.001 m 降至 2.507 m。因此在本次小样本配对中，强制 78° 与观察到的推进明显变化相关；没有进行推断检验，不能把它表述为统计显著差异。路线结果不能与这一因素混为同一个因素。

seed 74803 的 `R45` 单 seed 对照进一步显示强烈交互：

- 0.5 m/s、3 m 前视、0.20 m^-1：路线投影进度达到 100%，最小终点距离 2.901 m，随后在 step 9434 地形相对越界并摔倒；
- 0.5 m/s、5 m 前视、0.20 m^-1：只达到 14.13% 路线进度，净推进 6.092 m，无摔倒但长期停滞。

这说明“路线是否有效”依赖初始朝向、前视距离和低层策略的耦合，不能只选择一个表现最好的组合报告。

### 7.2 坡度调速没有修复停滞

在 `R45`、0.5 m/s、5 m 前视、0.20 m^-1 条件上，只新增一项高层规则：局部/前视坡度不超过 8° 时保持 0.5 m/s，8°--16° 线性降至 0.3 m/s。seed 74803 结果为：

- 净推进 6.314 m，路线进度 16.02%；
- 最小终点距离 83.648 m；
- 平均调度速度 0.353 m/s；
- 无摔倒，但四足悬空率 67.33%，接触速度超限率 23.97%；
- 无位置驻留、稳定驻留或合格完成。

与同一条件恒定 0.5 m/s 的 6.092 m 净推进和 14.13% 路线进度相比，该单 seed 变化不足以证明改善，且没有解决停滞。不能从已有机械功诊断量推导“更节能”，因为 V2 相对任务能耗尚未实现。

## 8. 可支持与不可支持的解释

当前证据支持：

- 高层候选路线在部分 reset 中可以改变并提高空间推进；
- 0.12 m^-1 曲率限制对当前候选路线过紧；
- 强制初始 yaw 对结果影响很大，必须作为独立因素；
- 部分长距离失败发生在路线末段的越界/过冲，而不只是坡面中段“爬不上去”；
- 低层支撑、触地与速度控制仍是合格完成的主导阻断因素。

当前证据不支持：

- 候选路线是时间或能耗最优路线；
- 机器人已完成稳定到达；
- 路线方法已经跨随机地图泛化；
- 坡度调速能够节能；
- 单纯增加训练时长必然解决问题。

## 9. 下一阶段建议

建议保持层级职责清晰：高层负责产生可行路线、前视点和速度/曲率命令；低层负责地形感知、稳定支撑和执行命令。下一阶段的顺序应为：

1. 先降低低层四足悬空和接触速度违规，否则任何路径比较都会被执行失败污染；
2. 对路线末段增加单独的高层终端接近逻辑，只改变“距最终目标较近时的速度/曲率/前视”，并与未改变条件配对；
3. 在固定地图上达到预先声明的稳定完成率后，再把 V2 能耗以只记录模式接入，验证量纲和漏洞；
4. 只有安全且稳定完成的路线才比较归一化时间与能耗，并报告多个 human-intent profile 和 Pareto 前沿；
5. 最后使用严格隔离的程序地图 train/validation/test seed 和多个独立训练 seed 检验泛化。
